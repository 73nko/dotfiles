Style Guide · v1.0

Sunset · Pool Splash

A summer-evening visual system for the terminal stack — Ghostty, tmux, Neovim, and Claude Code. A Miami-sunset gradient sets the mood; a turquoise pool holds it in balance. Warm tones carry syntax and state; cool tones carry structure and navigation. The tension between them is the whole idea.

Target Ghostty · tmux · Neovim · Claude Code Platform macOS Background translucent + blur
01

Design principles

01

Warm leads, cool balances.

Sunset pinks, corals, and tangerines drive identity. Pool turquoise is the counterweight — never just decoration. If a screen is all-warm, something is missing.

02

Accents earn their place.

Magenta and turquoise are loud. Use them for the things that matter: cursor position, active buffer, the current tmux window, the prompt glyph. Muted rosegold carries the rest.

03

The wallpaper is part of the theme.

A vertical sunset gradient (dusk → plum → wine → sunburn → peach) bleeds through the terminal background at ~30% opacity. Do not use a flat color desktop.

04

Glass, not chrome.

Heavy backdrop blur, rounded 14px window corners, soft inner glows instead of hard borders. This is a dusk pool deck, not a cockpit.

03

Typography & rhythm

  • Primary terminal font: Monaspace Neon at 13pt (macOS) — its rounded, glassy character fits the poolside mood. Enable stylistic ligatures (=>, !=).
  • Fallback: JetBrains Mono at the same size, weight 400 for code / 500 for statuslines.
  • Line height: 1.55–1.6. Airy, not compact. This is a lounging theme.
  • Cell padding: Ghostty window-padding-x = 16, window-padding-y = 12. Leave breathing room.
  • No bold for keywords — color carries weight. Reserve bold for statusline mode and clock.
  • Italic for comments only, and only if the font renders italic well (Monaspace Neon does).

Neovim bufferline (tabs)

  • Style: pill tabs — border-radius: 999px, no borders, transparent bar background.
  • Height: 28px. Padding 3px 14px, margin 4px 4px 4px 0.
  • Active: bg rgba(127,224,235,.22), fg #7FE0EB. (Pool pill.)
  • Inactive: bg rgba(255,198,160,.05), fg rgba(255,198,160,.5).
  • Modified dot: Magenta ●, 8px, 4px right of filename.
  • Filetype icon: render in its native color at 60% opacity.
  • No close × on tabs — cleaner.

06

Ghostty window

  • Background: #1E0A28 at 72% opacity, backdrop blur enabled.
  • Foreground default: #FFC6A0 (Rosegold).
  • Cursor: block, #FF8A3D (Tangerine). No blink. Cursor-line tint rgba(127,224,235,.06).
  • Selection bg: rgba(255,61,138,.22). Selection fg inherits.
  • Window padding: 16px horizontal, 12px vertical. Corner radius 14px.
  • Title bar: translucent, no background tint except a faint rgba(255,61,138,.04) wash. Title text rgba(255,198,160,.6), 11px.
  • macOS desktop wallpaper: linear gradient 175°: #1A0A28 0% → #3A1550 25% → #6A2050 55% → #C95A4A 85% → #F2A070 100%. Export as a 5K static image.

07

Shell prompt

Minimal, two-line. No powerline arrows in the prompt — keep those for the editor statusline so the pieces feel distinct.

  • Line 1: ~/code/networks in Turquoise Hi · main in Tangerine · ● Gold dot if dirty, ○ hollow if clean.
  • Line 2: Magenta ❯ glyph, single space, then input. On non-zero exit, change glyph to Tangerine ❯.
  • Duration: right-aligned on line 1 if command took >2s, format 2.4s in muted rosegold.
  • No hostname, no username. You know where you are.
08

Do & don't

Do

  • Let the sunset wallpaper bleed through the window at ~28–32% darkness
  • Use turquoise for structure (branch, session, clock, indent guides)
  • Use magenta for identity (keywords, mode, prompt, props)
  • Keep comments quiet — turquoise at 55% italic
  • Preserve the 60/12/12/8/5/3 usage ratio at a glance
  • Use rounded 999px pills for the bufferline and rounded 4px for tmux

Don't

  • Don't add green, red, or blue LSP-state colors — route everything through the 4 warm + 3 cool tokens
  • Don't bold keywords (color carries weight) — reserve bold for Mode and Clock
  • Don't use a flat black or solid desktop — the gradient is part of the theme
  • Don't let warm colors sit alone on a screen — if there's no turquoise visible, something is off
  • Don't introduce drop shadows on UI text — glass and glow only
  • Don't use emoji as icons in statuslines — use nerdfont glyphs

10

Implementation checklist

For the agent applying this guide

  • Produce a 5K desktop wallpaper matching the gradient spec in §06.
  • Ghostty: config with background + opacity + cursor + selection + ANSI palette + padding + radius.
  • Neovim: colorscheme that maps every Treesitter capture listed in §04. No highlight group should be left at its default.
  • Neovim: configure bufferline plugin with pill tabs per §04. Enable relative numbers, indent guides (1px, alpha 12%), signcolumn.
  • Neovim: statusline plugin configured to the powerline layout in §04, nerdfont glyphs required.
  • tmux: status bar bottom, height 1, segments and colors per §04. Pane borders cool-when-active, warm-when-idle.
  • tmux: prefix + copy-mode indicators tinted Magenta to stay on-theme.
  • Claude Code CLI: terminal color overrides (if supported) to ensure + diffs render Turquoise Hi and tool titles Tangerine.
  • Shell prompt: Starship or similar, matching §07 two-line spec. Two-line.
  • Verify the 60/12/12/8/5/3 usage ratio on a real screen — if cool accents disappear, rebalance.
  • Nerdfont installed and set in Ghostty (recommended: Monaspace Neon NF, fallback JetBrains Mono NF).
