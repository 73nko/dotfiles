Style Guide · v2.0

Glacier · Signal

A glacial cyan visual system for the terminal stack — Ghostty, tmux, Neovim, and daily tools. Deep blue-green surfaces echo the mountain shadows; cyan carries focus and identity; coral is reserved for warnings and destructive state. The wallpaper supplies the light.

Target Ghostty · tmux · Neovim · Claude Code Platform macOS Surface translucent glass · blur 28–40px Palette 2 variations
01

Design principles

01

Quiet wins.

Saturation is the budget; we spend almost none. Accents are pastel-bright, not neon. If a color demands attention from across the room, it's wrong for this theme.

02

Cool sets the tone.

Cyan, steel, and ice carry the system. Coral is deliberately scarce, mirroring the signal lights in the wallpaper and preserving its urgency.

03

Glass over chrome.

Window backgrounds are 55% opaque over heavy blur. The mountain wallpaper bleeds through everywhere. No solid panels, no hard borders — 1px hairlines at 10–22% alpha.

04

The wallpaper is the lighting rig.

Every surface borrows color from the landscape behind it. The single source image and its tracked crops are part of the system, not decoration.

02

The wallpaper

The supplied ultrawide artwork is the source of truth. Display-specific crops keep the wolf and the coral ship signal visible while preserving the misty cyan landscape.

04

Typography & rhythm

  • Primary terminal font: Monaspace Neon at 13.5pt (macOS). Rounded, glassy — fits the mood. Stylistic ligatures on for =>, !=, ===.
  • Fallback: JetBrains Mono at the same size, weight 400 code / 500 chrome.
  • Line height: 1.6–1.7. More air than Sunset · Pool Splash — the glass needs room to breathe.
  • Cell padding: Ghostty window-padding-x = 18, window-padding-y = 14.
  • No bold for keywords. Color is dim enough that you'd lose the cue. Reserve bold for statusline mode + clock only.
  • Italic for comments — at 50% alpha. The comment shouldn't compete with the code.
  • Disable cursor blink. Block cursor in Mint Mist — visible but not insistent.

Ghostty window

  • Background: --night at 55% opacity, background-blur-radius = 40.
  • Foreground default: --snow (#f3faf7).
  • Cursor: block, --mint. No blink. Cursor-line tint rgba(ice, .06).
  • Selection bg: rgba(signal, .22).
  • Window padding: 18 horizontal, 14 vertical. Corner radius 14px (macOS).
  • Title bar: translucent. Title text Silver, 11px.

08

Shell prompt

Two-line. No powerline. Path + branch on line one; glyph + input on line two.

~/code/acme-api fix/rate-limit-race ○2.4s
❯ claude
~/projects/neetcode-ts main ●
❯ npm test
  • Line 1: path Ice; branch Mint Mist with nerdfont glyph; dirty Frost ●, clean Azure ○.
  • Line 2: Signal ❯. On non-zero exit, swap to Mint Mist ❯.
  • Duration: right-aligned on line 1 if > 2s, Silver · 58%.
  • No hostname, no username, no $. Trust the room.

10

Do & don't

Do

  • Let the wallpaper bleed through at ~45% — the sky is supposed to show
  • Keep accents in pastel range (HSL L 70–90) — no neon
  • Use Steel for structure (branch, position, clock, indent guides)
  • Use Signal for identity (keywords, mode, prompt, modified dot)
  • Keep comments at Ice · 50% · italic — quiet
  • Preserve the 60/14/12/8/4/2 ratio — count visible accents on screen

Don't

  • Don't add a single saturated color — even one pure red breaks the mood
  • Don't use a solid background — glass + wallpaper is the whole point
  • Don't bold keywords — the color is doing the work, stacking weight buries it
  • Don't introduce drop shadows on text — softens everything below the legibility floor
  • Don't bring back powerline arrows — flat segments only
  • Don't substitute emoji for nerdfont glyphs — emoji color clashes with the palette

12

Implementation checklist

For the agent applying this guide

  • Keep the tracked source image and regenerate display crops with scripts/generate_wallpaper.py.
  • Ghostty: config with background + opacity 0.55 + blur 40 + cursor + selection + ANSI palette + padding 18/14 + radius 14.
  • Neovim: colorscheme mapping every Treesitter capture in §05. No highlight group at default.
  • Neovim: bufferline plugin with pill tabs, signcolumn relative-numbers, indent guides 1px @ 10%.
  • Neovim: statusline flat (no powerline arrows), nerdfont glyphs.
  • tmux: status bar bottom, height 1. Pane borders cool-when-active.
  • Claude Code: override + diff → Ice, tool title → Mint Mist if config supports.
  • Shell prompt: Starship, two-line per §08.
  • Verify the 60/14/12/8/4/2 ratio on a real screen — if structural cool disappears, rebalance.
  • Nerdfont set in Ghostty (Monaspace Neon NF preferred, JetBrains Mono NF fallback).
  • Test both palette variations (Glacier Signal + Snow Lake) against the tracked wallpaper.
