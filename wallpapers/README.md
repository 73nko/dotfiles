# Glacier Signal wallpaper outputs

This directory contains generated, ignored display crops. The source image
lives in the private layer at
`personal/assets/wallpapers/glacier-signal-source.jpg` and is intentionally not
published with the public dotfiles repository.

Regenerate all Mac, mobile, and Chrome new-tab variants with:

```sh
python3 ~/.config/scripts/generate_wallpaper.py
```
